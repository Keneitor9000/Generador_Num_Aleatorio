# Generador de Números Aleatorios

Aplicación Android que genera un número aleatorio entre un mínimo y un máximo introducidos por el usuario.

## Tecnologías
- Android Studio
- Java/Kotlin

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Keneitor9000/Generador_Num_Aleatorio.git
   ```
2. Abre el proyecto en Android Studio.
